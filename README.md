## Featured Projects

### MigraineGuardian

An AI-powered migraine early warning and decision-support system that analyzes lifestyle and weather-related factors to estimate daily migraine risk.

**Key Features**
- Lifestyle and weather based risk prediction
- Machine Learning models with SHAP based explanations
- RAG powered chatbot for contextual assistance
- FastAPI service for ML inference

**Tech:** • Python • Scikit-learn • SHAP • FastAPI • MongoDB • RAG

---

### Bharatanatyam Learning App

An AI-powered learning application for real-time Bharatanatyam mudra and pose recognition using computer vision and deep learning.

**Key Features**
- Real-time mudra and pose recognition
- Custom dataset creation and preprocessing
- Computer Vision and deep learning-based recognition
- Flutter-based mobile application
- Real-time pose accuracy evaluation

**Tech:** YOLO • CNN • OpenCV • MediaPipe • PyTorch • Flutter

**Achievement:** Smart India Hackathon 2025 — Winner

---

### RAG Chatbot

A Retrieval-Augmented Generation chatbot designed to provide contextual responses from a custom knowledge base while maintaining conversational context.

**Key Features**
- Document ingestion and intelligent chunking
- Embeddings and vector search
- Context-aware response generation
- Conversational memory using MongoDB
- Source-aware responses and citations

**Tech:** MongoDB Atlas • Groq • Express.js • React.js

---

### Hospital Management System

A full-stack hospital management application designed to streamline patient registration and appointment scheduling.

**Key Features**
- Patient registration and management
- Appointment scheduling
- Role-based authentication
- RESTful backend APIs
- MongoDB-based data management

**Tech:** MongoDB • Express.js • React.js • Node.js
